# 🎮 3D Шутер от первого лица

Бесплатный **офлайн 3D шутер** на чистом JavaScript + Three.js.  
Работает на ПК и смартфонах. Не требует интернета после загрузки!

![favicon](favicon.ico)

## 🌟 Особенности

- ✅ Полностью **офлайн** — работает без интернета
- 📱 **Адаптивное управление** — ПК (мышь + клавиатура) и смартфоны (джойстик + кнопки)
- 🌌 **Звёздное небо** — 3000 процедурных звёзд
- 🔊 **Процедурные звуки** — выстрелы и взрывы генерируются через Web Audio API
- 💥 **Неоновая графика** — светящиеся мишени, цветные лампы, частицы
- 🎯 **Raycast-стрельба** — точное попадание в цель
- 🚫 **Без рекламы и трекеров** — никаких внешних запросов

## 🕹️ Управление

### 💻 На ПК:
- **Стрелки** — движение
- **Мышь** — осмотр
- **Пробел / ЛКМ** — выстрел
- **ESC** — пауза

### 📱 На смартфоне:
- **Левый круг (джойстик)** — движение
- **Правая часть экрана** — осмотр (проведите пальцем)
- **Красная кнопка "ОГОНЬ"** — выстрел

## 🚀 Как запустить

1. Скачайте или клонируйте репозиторий
2. Откройте файл `index.html` в любом браузере
3. Нажмите "НАЧАТЬ" и играйте!
